# Pazuduso_mantu_lietotne
Pazudušo mantu lietotne skolas ietvaros. Veidots ar Flask.<br><br>
 __Apraksts__<br>
Lietotne ir paredzēta skolēnijem saistībā ar puzudušajām,nozaudētajām mantām.
## instalācija un lietošana <br>
Pēc atarhivēšanas:<br>
jāuzinstelē: 
- python 3.12
- flask <br>

Palaišana:<br>
Uzrakstot terminālī ``flask run``
## _lietošana_
Lietotājiem, bez konta ir iespejams pieteikties pievienotajām mantām, ievadot vārdu,<br> kā arī apskatīt arhīvu ar mantām pēdējo divu nedēļu laikā.<br><br>
Konta lietotājiem ir iespējams pievienot mantas ievadot,to nosaukumu,aprakstu,kur atrasta,kad atrasta un bildi ar to,<br> kas pēcatam paradās sākuma lapā.<br>
Vel ir opcija mantas atsaukt atpakaļ no arhīva, vai tās noņemt pilnībā.
